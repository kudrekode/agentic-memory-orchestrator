## 28-09-26 — SQLite as memory store

**Decision:** Use SQLite as the canonical local memory database.

**Why:**
- local
- zero infrastructure
- easy backup
- easy inspection
- appropriate scale for one developer

**Alternatives considered:**
- Markdown-only memory
- Postgres
- vector database

**Reason rejected:**
Markdown is useful for humans but awkward for structured updates and retrieval.
Postgres/vector DB adds unnecessary infrastructure at this stage.
